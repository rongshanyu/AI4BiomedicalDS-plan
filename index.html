第 1 讲：课程介绍与 AI 使用技巧 （yu)

主题 科研训练中的 AI 工具使用：能做什么，不能做什么。

核心问题

  • AI 可以如何帮助文献调研、代码实现、数据分析和写作？
  • 使用 AI 时有哪些风险？
  • 如何建立可复现的科研工作环境？

主要内容

  • 课程目标、考核方式、最终项目说明
  • AI 在科研中的典型用途：
  • 查找和总结文献
  • 解释统计和机器学习概念
  • 辅助写代码和 debug
  • 润色英文论文
  • 生成图表说明和结果解释
  • AI 使用注意事项：
  • 不直接相信 AI 给出的文献和结论
  • 重要事实必须回到原始文献或官方文档核查
  • 不上传隐私数据、病人信息或未公开实验数据
  • AI 生成代码必须自己运行、检查、理解
  • AI 可以辅助写作，但不能替代科学判断

工具环境

  • VS Code
  • Codex / ChatGPT
  • DeepSeek / GLM / Kimi 等大模型工具
  • Git / GitHub
  • Python / Jupyter Notebook
  • 常用包：numpy, pandas, scipy, scikit-learn, matplotlib, seaborn

Checkpoint 检验学生需要完成：

  1. 成功安装或打开 VS Code
  2. 成功运行一个 Python notebook
  3. 成功使用 Git 初始化或克隆一个仓库
  4. 完成一次 commit
  5. 使用 AI 工具解释一段代码，并指出其中可能的问题
  6. 提交一页简短说明：自己准备用 AI 辅助哪些科研环节，以及如何避免误用

课堂练习给学生一个简单数据表，让他们用 AI 辅助完成：

  • 解释每一列变量含义
  • 写出 pandas 读取代码
  • 生成一个描述性统计表
  • 检查 AI 代码是否能真实运行

第 2 讲：变量类型与数据类型 (zhang)

主题 理解数据，是所有统计分析和机器学习建模的起点。

核心问题

  • 什么是变量？
  • 不同变量类型决定了哪些统计方法和模型可以使用？
  • 生物医学数据有哪些特殊性？

主要内容

  • 变量类型：
  • 连续变量：年龄、血压、基因表达量
  • 离散变量：突变数量、细胞计数
  • 二分类变量：患病/未患病，阳性/阴性
  • 多分类变量：疾病亚型、细胞类型
  • 有序变量：疾病分期、评分等级
  • 时间变量：生存时间、随访时间
  • 高维变量：基因表达矩阵、蛋白组、影像特征
  • 数据矩阵的基本形式：
  • 样本 × 特征
  • 患者 × 临床指标
  • 细胞 × 基因
  • 图像 × 像素/特征
  • 数据质量问题：
  • 缺失值
  • 异常值
  • 批次效应
  • 类别不平衡
  • 测量误差

课堂练习给出一个临床数据表，让学生判断每一列的变量类型，并回答：

  • 哪些变量可以求均值？
  • 哪些变量适合做卡方检验？
  • 哪些变量适合进入 logistic regression？
  • 哪些变量需要标准化？

作业选择一个公开生物医学数据集，写出：

  • 数据来源
  • 样本数
  • 特征数
  • 主要变量类型
  • 可能的数据质量问题

第 3 讲a：高维数据与维度灾难 （zhang)

主题 为什么生物医学数据经常“变量很多，样本很少”？

核心问题

  • 什么是高维数据？
  • 为什么高维会带来统计和机器学习困难？
  • 什么是维度灾难？

主要内容

  • 高维数据例子：
  • 转录组：几万个基因
  • 蛋白组：几千个蛋白
  • 代谢组：数百到数千个代谢物
  • 医学影像：大量像素或深度特征
  • 单细胞数据：细胞数多、基因数多、噪声大
  • 维度灾难：
  • 样本之间距离变得不可靠
  • 模型容易记住训练数据
  • 统计检验数量急剧增加
  • 可视化困难
  • 噪声特征可能掩盖真实信号
  • “大 p 小 n”问题：
  • p = 特征数
  • n = 样本数
  • 生物医学研究中常见 p >> n

课堂练习用二维、三维和高维模拟数据展示：

  • 距离分布如何随维度变化
  • 高维下最近邻和最远邻差异变小
  • 为什么高维数据更容易过拟合

作业 用自己的话解释：为什么“特征越多”不一定意味着“模型越好”？

第 3 讲b：降维、PCA 与 UMAP (zhang)

主题 如何把复杂高维数据压缩到可理解的低维空间？

核心问题

  • 降维是为了可视化，还是为了建模？
  • PCA 和 UMAP 有什么区别？
  • 如何避免过度解释降维图？

主要内容

  • 降维目的：
  • 可视化
  • 去噪
  • 压缩特征
  • 发现样本结构
  • 作为后续建模输入
  • PCA：
  • 线性降维
  • 最大化方差解释
  • 主成分
  • explained variance
  • loading 的含义
  • UMAP：
  • 非线性降维
  • 更适合展示局部结构
  • 常用于单细胞和复杂表型数据
  • PCA vs UMAP：
  • PCA 更容易解释
  • UMAP 更适合可视化复杂结构
  • UMAP 图中的距离和簇不能过度解释
  • 常见错误：
  • 把 UMAP 上的簇直接当作生物学真相
  • 在全数据上先降维再交叉验证，导致信息泄露
  • 不做标准化就直接 PCA

课堂练习用一个 gene expression 或 clinical-feature 数据集：

  • 标准化数据
  • 做 PCA
  • 画 PC1 vs PC2
  • 做 UMAP
  • 比较两种图的差异

作业解释：

  • PCA 第一主成分代表什么？
  • 为什么 PCA 前通常需要标准化？
  • UMAP 图能说明什么，不能说明什么？

第 4 讲：统计检验与假设设计 (ji)

主题 科研问题如何转化为可检验的统计假设？

核心问题

  • 什么是 hypothesis test？
  • 什么是原假设和备择假设？
  • 什么是 Type I error 和 Type II error？
  • 如何选择合适的统计检验方法？

主要内容

  • 假设检验基本框架：
  • Null hypothesis, H0
  • Alternative hypothesis, H1
  • p-value
  • significance level
  • confidence interval
  • Type I error：
  • 假阳性
  • 把没有差异判断成有差异
  • Type II error：
  • 假阴性
  • 把真实差异判断成无差异
  • Power：
  • 检出真实效应的能力
  • 与样本量、效应大小、噪声有关
  • 如何设计假说：
  • 从生物医学问题出发
  • 明确比较对象
  • 明确主要终点
  • 避免事后找显著性
  • 常见统计检验选择：
  • t-test
  • Mann–Whitney U test
  • paired t-test
  • Wilcoxon signed-rank test
  • chi-square test
  • Fisher’s exact test
  • ANOVA
  • correlation test
  • linear regression
  • logistic regression

课堂练习给出几个问题，让学生判断应使用什么统计方法：

  1. 比较两组患者年龄是否不同
  2. 比较治疗前后同一患者指标是否变化
  3. 比较疾病组和对照组中性别比例是否不同
  4. 检验某基因表达量是否与药物反应相关
  5. 检验某指标是否预测是否患病

作业设计一个完整假设检验问题，包括：

  • 科学问题
  • H0
  • H1
  • 变量类型
  • 拟使用统计检验
  • 可能的混杂因素

第 5讲：多重检验校正 (ji)

主题 为什么做很多次检验时，p < 0.05 不再可靠？

核心问题

  • 什么是多重检验问题？
  • 为什么组学数据特别容易产生假阳性？
  • FDR 和 Bonferroni 有什么区别？

主要内容

  • 多重检验的来源：
  • 同时检验几千个基因
  • 同时比较多个临床指标
  • 多个亚组分析
  • 多个模型和多个终点
  • 为什么会产生假阳性：
  • 如果做 1000 次检验，即使没有真实差异，也可能出现约 50 个 p < 0.05
  • 常见校正方法：
  • Bonferroni correction
  • Benjamini–Hochberg FDR
  • q-value
  • 何时使用哪种方法：
  • Bonferroni 更严格，适合检验数量较少、错误代价高的场景
  • FDR 更常用于组学数据和探索性研究
  • 显著性与生物学意义：
  • p 值显著不等于效应大
  • 需要同时报告 effect size
  • 需要结合可重复性和机制解释

课堂练习模拟 1000 个随机基因表达数据，观察：

  • 未校正 p 值中有多少假阳性
  • Bonferroni 后剩多少
  • FDR 后剩多少

作业解释以下三个概念：

  • p-value
  • adjusted p-value
  • false discovery rate

第 6 讲：机器学习基础与朴素贝叶斯 (liu)

主题 从统计检验走向预测模型。

核心问题

  • 什么是数据模型？
  • 什么是训练、预测和泛化？
  • 什么是损失函数？
  • 如何评价一个模型？

主要内容

  • 机器学习基本流程：
  • 数据输入
  • 特征
  • 标签
  • 训练集
  • 验证集
  • 测试集
  • 模型训练
  • 性能评估
  • 什么是数据模型：
  • 用数学函数描述输入和输出之间的关系
  • 例如：根据症状、检验指标预测疾病状态
  • 什么是损失：
  • 模型预测与真实标签之间的差距
  • 常见损失：cross-entropy, mean squared error
  • 模型评估：
  • accuracy
  • sensitivity
  • specificity
  • precision
  • recall
  • F1-score
  • ROC-AUC
  • PR-AUC
  • calibration
  • 朴素贝叶斯：
  • 基于 Bayes theorem
  • “朴素”假设：特征之间条件独立
  • 适合文本分类、简单医学分类任务
  • 优点与局限：
  • 简单、快速、可解释
  • 条件独立假设常常不完全成立

课堂练习用一个小型症状数据集训练朴素贝叶斯模型：

  • 输入：症状特征
  • 输出：是否患病
  • 计算 sensitivity 和 specificity

作业 解释为什么医学诊断模型不能只看 accuracy。

第 7讲：线性模型、LDA 与 Logistic Regression (liu)

主题 简单模型为什么仍然重要？

核心问题

  • 什么是线性分类？
  • LDA 和 logistic regression 有什么区别？
  • 为什么 logistic regression 在医学研究中非常常用？

主要内容

  • 线性模型基本思想：
  • 用特征的加权和进行预测
  • 权重可以反映变量贡献
  • LDA：
  • 假设不同类别服从高斯分布
  • 寻找区分类别的线性方向
  • Logistic regression：
  • 输出概率
  • 常用于二分类医学问题
  • odds ratio 的解释
  • Linear regression vs logistic regression：
  • linear regression 预测连续值
  • logistic regression 预测类别概率
  • 医学中的应用：
  • 疾病风险预测
  • 预后分析
  • 生物标志物筛选
  • 注意事项：
  • 共线性
  • 特征标准化
  • 类别不平衡
  • 变量选择
  • 解释不能等同于因果

课堂练习用 clinical dataset 建立 logistic regression：

  • 划分训练集和测试集
  • 训练模型
  • 输出系数
  • 计算 AUC、sensitivity、specificity
  • 解释一个变量的方向和意义

作业 比较 LDA 和 logistic regression 的适用场景。

第 8 讲：SVM 与 Margin (wang)

主题 如何寻找一个“最稳健”的分类边界？

核心问题

  • 什么是 margin？
  • 为什么最大化 margin 有助于泛化？
  • kernel trick 是什么？

主要内容

  • SVM 的基本思想：
  • 找到一个分类超平面
  • 最大化类别之间的 margin
  • Margin：
  • 样本到分类边界的距离
  • margin 越大，模型对扰动越稳健
  • Support vectors：
  • 决定分类边界的关键样本
  • Soft margin：
  • 允许少量分类错误
  • 通过参数 C 控制误差和 margin 的权衡
  • Kernel：
  • linear kernel
  • polynomial kernel
  • RBF kernel
  • 优点：
  • 适合中小样本
  • 在高维数据中表现好
  • 局限：
  • 参数敏感
  • 大数据上训练慢
  • 可解释性有限

课堂练习用二维模拟数据展示：

  • 不同 C 对分类边界的影响
  • linear kernel 与 RBF kernel 的区别
  • margin 如何变化

作业 用自己的话解释：为什么 SVM 不是简单地找一条“刚好分开两类”的线？

第 9讲：集成学习与 Bootstrapping (wang)

主题 多个弱模型如何组合成更稳定的强模型？

核心问题

  • 什么是 ensemble learning？
  • 什么是 bootstrapping？
  • Random Forest 和 boosting 的思想是什么？

主要内容

  • 集成学习基本思想：
  • 多个模型共同投票或加权
  • 降低单一模型的不稳定性
  • Bagging：
  • bootstrap sampling
  • 多个模型并行训练
  • Random Forest 是典型方法
  • Bootstrapping：
  • 有放回抽样
  • 用于估计模型稳定性和不确定性
  • Random Forest：
  • 多棵决策树
  • 随机选择样本
  • 随机选择特征
  • Boosting：
  • 后一个模型关注前一个模型的错误
  • 例如 AdaBoost, Gradient Boosting, XGBoost
  • 优点：
  • 表现稳定
  • 能处理非线性关系
  • 对变量尺度不太敏感
  • 局限：
  • 可解释性下降
  • 容易被误用为“黑箱高性能模型”
  • 仍然需要严格验证

课堂练习 比较 logistic regression、SVM 和 random forest 在同一数据集上的表现。

作业 解释 bagging 和 boosting 的区别。

第 10 讲a：欠过拟合的识别 (yu)

主题 模型看起来很好，为什么可能是假的？

核心问题

  • 什么是过拟合？
  • 如何判断一个模型是否过拟合？
  • 生物医学研究中常见的信息泄露有哪些？

主要内容

  • 过拟合定义：
  • 模型学习了训练数据中的噪声，而不是可泛化规律
  • 典型表现：
  • 训练集表现很好，测试集表现差
  • 交叉验证结果波动大
  • 外部数据集表现明显下降
  • 模型依赖少数异常样本
  • 常见原因：
  • 样本量太小
  • 特征太多
  • 模型太复杂
  • 数据泄露
  • 重复调参后只报告最好结果
  • 生物医学中的信息泄露：
  • 标准化在全数据上完成，而不是只在训练集上拟合
  • 特征选择在全数据上完成
  • 同一患者的多个样本同时出现在训练集和测试集
  • 测试集被反复用于调参
  • 数据增强前后样本分到不同集合

课堂练习 设计一个“错误流程”和一个“正确流程”，让学生比较模型性能差异。

作业 阅读一段机器学习方法描述，指出其中可能的信息泄露风险。

第 10 讲b：过拟合的对抗：正则化与验证策略 （yu)

主题 如何让模型更稳健、更可信？

核心问题

  • 什么是正则化？
  • L1 和 L2 有什么区别？
  • 如何设计训练集、验证集和测试集？
  • 为什么外部验证很重要？

主要内容

  • 防止过拟合的方法：
  • 增加样本量
  • 减少特征数量
  • 特征选择
  • 正则化
  • 交叉验证
  • early stopping
  • dropout
  • 数据增强
  • 外部验证
  • 正则化：
  • L1 regularization
  • L2 regularization
  • Elastic Net
  • L1：
  • 产生稀疏特征
  • 有助于变量选择
  • L2：
  • 缩小权重
  • 提高稳定性
  • 验证策略：
  • train/validation/test split
  • k-fold cross-validation
  • nested cross-validation
  • external validation
  • 医学模型报告建议：
  • 不只报告平均性能
  • 报告置信区间或标准差
  • 报告 sensitivity 和 specificity
  • 报告校准情况
  • 说明数据划分方式

课堂练习对 logistic regression 分别加入 L1 和 L2 正则化，观察：

  • 系数变化
  • 特征数量变化
  • 测试集性能变化

作业 为一个小样本高维数据设计一个合理的验证方案。

第 11 讲：生物医学问题建模与课程项目汇报 (ji)

主题 从真实医学问题到可执行科研项目。

核心问题

  • 如何把一个宽泛兴趣变成具体研究问题？
  • 如何定义输入、输出、基线模型和评价指标？
  • 如何写一个清楚、可执行的 research proposal？

主要内容

  • 生物医学建模基本流程：
  • 明确临床或生物学问题
  • 明确研究对象
  • 明确预测目标或解释目标
  • 明确数据来源
  • 明确变量和标签
  • 明确 baseline method
  • 明确 evaluation metrics
  • 明确可能偏倚和局限性
  • 明确结果如何解释
  • 研究问题示例：
